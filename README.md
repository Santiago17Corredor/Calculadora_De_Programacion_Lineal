# Calculadora de Programacion Lineal

Aplicacion de escritorio en Python para construir y resolver problemas de
programacion lineal con dos variables de decision.

La primera entrega contempla:

- metodo grafico para maximizacion y minimizacion;
- metodo Simplex para maximizacion;
- interfaz grafica con Tkinter;
- visualizacion del procedimiento y los resultados.

El proyecto se desarrolla de forma incremental. La version actual es `v0.1`,
correspondiente a planeacion y diseno.
